# Task 2 - Data Visualization and Storytelling

## Objective
Create a professional Power BI dashboard using the Superstore dataset to present meaningful business insights.

## Tools Used
- Power BI
- Superstore Dataset

## Dashboard Includes
- Total Sales
- Total Orders
- Average Sales
- Sales by Category
- Sales Trend
- Sales by Region
- Sales by Segment
- Top 10 States
- Sales by Ship Mode

## Key Insights
- Technology generated the highest sales.
- West region contributed the highest revenue.
- Standard Class was the most used shipping mode.
- Consumer segment dominated sales.
